# Security Policy

Report security issues privately to <paudley@blackcatinformatics.ca>.

`visual-hashing` renders deterministic, non-secret visual fingerprints from
input bytes. It is not an authentication protocol, signature scheme, password
hash, or encryption primitive. Do not rely on it as a substitute for
cryptographic verification.

Supported versions are the current crates.io release and the current `main`
branch. Security fixes are released through crates.io.
