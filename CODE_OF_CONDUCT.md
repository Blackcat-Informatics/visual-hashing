# Contributor Code of Conduct

`visual-hashing` is a professional open source project stewarded by Blackcat
Informatics® Inc. Be respectful, direct, and constructive in issues, reviews,
and discussions.

Unacceptable behavior includes harassment, discriminatory language, personal
attacks, deliberate disruption, or publishing private information without
permission.

Report conduct concerns privately to <paudley@blackcatinformatics.ca>. Reports
will be reviewed by project maintainers and handled proportionately.
